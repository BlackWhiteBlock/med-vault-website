本模块由两个根级配置文件组成：`.gitignore` 按类别分组声明需排除的版本控制条目（依赖、构建产物、环境变量、日志、工具缓存、测试覆盖率、TypeScript、操作系统、编辑器、临时打包），并通过 `!.env.example` 显式保留示例模板；`.github/workflows/deploy-figma-ui-pages.yml` 定义名为 Deploy static site (figma-ui) 的 workflow，仅在 `workflow_dispatch` 触发，使用 Node 20 在 `figma-ui` 目录下执行 `npm install && npm run build`，根据仓库类型动态计算 `VITE_BASE_URL`（用户主页仓库用 `/`，普通仓库用 `/<repo>/`），通过 `actions/upload-pages-artifact@v3` 上传 `figma-ui/dist` 并由 `actions/deploy-pages@v4` 发布到 GitHub Pages，同时启用 concurrency 组 `pages` 以取消进行中的重复部署。该工作流当前已切换至阿里云 ESA Pages，默认不再随 push 自动运行。
