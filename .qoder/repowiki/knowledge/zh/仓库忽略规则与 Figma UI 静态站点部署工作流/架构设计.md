本模块由两个根级配置文件组成：`.gitignore` 集中声明需排除的版本控制条目，覆盖 node_modules、dist/build/out 等构建产物、.env 系列环境变量（保留 .env.example）、各类日志、Vite/Parcel/Turbo 缓存、TypeScript 编译信息、操作系统临时文件以及编辑器本地配置；`.github/workflows/deploy-figma-ui-pages.yml` 是一个 GitHub Actions 工作流，仅在 `workflow_dispatch` 时触发，使用 Node 20 在 `figma-ui` 目录下执行 `npm install && npm run build`，根据仓库类型动态计算 `VITE_BASE_URL`（用户主页仓库用 `/`，普通仓库用 `/<repo>/`），通过 `actions/upload-pages-artifact@v3` 上传 `figma-ui/dist` 并由 `actions/deploy-pages@v4` 发布到 GitHub Pages，同时启用 concurrency 组 `pages` 以取消进行中的重复部署。该工作流当前已切换至阿里云 ESA Pages，默认不再随 push 自动运行。
